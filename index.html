              Sheet 02 Method

              How I build with agents

              An agent is an AI model that can use tools to finish a task. Here's the setup I use, in four steps, with one example: the agentic rules engine I launched at Zuora. A billing admin describes a pricing rule in plain English, and the agent builds it with the right feature.

              1. 1

                Give it the right information

                I connect the data the task needs and leave out the rest. In my experience, missing information causes more mistakes than the wording of the prompt.

                ExampleThe customer's products, price plans and custom fields, plus how each rule feature works.

                Context · MCP
              2. 2

                Let one agent do the work

                One agent plans the steps and uses tools to carry them out, including picking the right tool for the job. I add helper agents only when steps can run at the same time.

                ExampleMatches the request to the right feature: a decision table for lookups, a decision tree for if-then steps, a JavaScript function for custom math.

                Tool use · Subagents
              3. 3

                Check the work

                Before building, I write tests that describe a good result. Every change has to pass them, including tests where an agent clicks through the product like a user.

                ExampleRuns the rule against sample billing cases, fixes what fails and runs them again.

                Evals · Computer use
              4. 4

                A person signs off

                Small actions that can be undone run on their own. Bigger ones wait for a person. I widen the limits only as results hold up.

                ExampleThe admin reviews the rule and its test results before it touches live billing.

                Human in the loop

              Also part of the setup: saved instructions agents can reuse (skills), the smallest model that handles each step well, and hosted platforms for long-running tasks.
